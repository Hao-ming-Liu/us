# us

两个人共写的纪念册。一次见面有一条时间线，每个事件是一篇有封面的帖子。两个人可以在帖子下续写、贴图，并为每一条感想单独署名。

## 在电脑上体验

在项目根目录打开终端，运行下列命令，然后打开 <http://localhost:4173>。按 Ctrl+C 可以关闭服务。

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory site
```

首页提供小满和阿川两个演示身份。用一个身份写留言，退出后用另一个身份查看首页提醒，两人的演示内容保存在同一浏览器。演示内容可由使用这台设备的人访问。正式记录使用下方的私人空间。

首页放映回忆中的照片，可用照片下方的按钮暂停或翻页。在「空间设置」里的「首页放映」可以调整自动轮播、切换间隔和感想气泡。电脑上把鼠标移到右边缘的小把手即可展开导航；手机上向左滑动或轻点把手也可以展开。

打开某次见面，点右上角「添加事件」，再点曲线上的落点；也可以直接把按钮拖过去。已有事件气泡可以拖动调序，或者点气泡上的拖动手柄选择位置。移动只改变展示顺序，事件日期保留。

进入「信箱」可以一起查看留言和未来信，也可以只看其中一种，按时间正序、逆序或日期区间翻找。用阿川的身份打开示例信，点击信封即可拆开阅读。首页的收件提醒只显示来自对方的类型和收到时间。

## 建立私人空间

1. 根据 [后台配置](supabase/README.md) 创建免费的 Supabase 项目，运行数据库脚本，预先创建两个账号并设置配对名单。
2. 在 [网页配置](site/config.js) 填写项目 URL 和 **publishable key**。这个文件会公开，请保管好管理密钥、密码和数据库连接串。
3. 用第一个账号登录，生成一次性邀请码，私下发给伴侣。伴侣用第二个账号登录并接受，两端即可打开共同的纪念册。

## 发布到 GitHub Pages

1. 创建 GitHub 免费公开仓库，默认分支使用 `main`。提交本项目的 `site/`、`.github/workflows/pages.yml` 和配置说明。账号邮箱的配置 SQL 在 Supabase 控制台执行，真实照片和备份保存在私人空间或自己的设备中。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 在 **Actions → 发布 us → Run workflow** 运行发布任务。成功后从任务页面打开网址。以后更新 `site/` 并推送到 `main` 就会自动发布。
4. 上线后，用无痕窗口确认需要登录才能打开自己的记录。在手机和电脑各登录一个账号，发一条留言、读信、上传一张照片并导出一次备份。

## 保存回忆

未来信按上海时间计算，在选定日期的次日零点起对收信人可见。收信人导出的备份也遵循这个时间。备份包含文字、媒体文件和可离线阅读的页面，解压后打开 `index.html`。备份含可阅读的私人内容，请保存在自己的设备中。

照片会缩小后上传；视频限 60 秒、20 MiB。免费后台容量和闲置暂停规则以 [Supabase 定价页](https://supabase.com/pricing) 为准。建议保留原件，并在每次整理完一次见面的记录后导出备份。
